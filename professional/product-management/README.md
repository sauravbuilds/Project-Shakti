# Product Management

**Path:** `professional/product-management/`

This is the craft I already practice daily as a PM, tracked here with the same rigor as everything else in this repo. Nothing in here is theoretical: it's the actual work, studied and applied.

Same rule as everywhere else: **actions don't count, progress does.** Finishing a course or reading a framework means nothing on its own. What matters is the before and after: what I couldn't reason about or do before, that I can now.

## Structure

There is no fixed set of folders here. As a new block of PM work comes up, whether it's a course , a framework, a real decision made at work, or something else, a new folder is created for it and this README is updated to reflect it.

## Format

Each entry follows the same shape:

- **Baseline** → what I could do, or knew, before
- **What changed** → what I did (studied, drilled, decided, shipped)
