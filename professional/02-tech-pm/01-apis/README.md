# APIs

**Path:** `professional/02-tech-pm/01-apis/`

How software talks to software. Reading API docs, testing calls, authentication, webhooks, and the edge cases (limits, errors, retries) that decide whether an integration holds up.

## Topics

One file per topic, added as I learn it. Files, not folders.

- HTTP and REST basics
- Reading API docs and testing calls with Postman or curl
- Authentication: API keys, tokens, OAuth
- Webhooks and events
- Rate limits, errors, and retries
- Pagination, idempotency, and versioning
- API-first product thinking
- SDKs, and how models and tools connect through APIs

- **What changed** → what I studied or tried
