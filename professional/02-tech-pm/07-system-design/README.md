# System Design

**Path:** `professional/02-tech-pm/07-system-design/`

HLD and LLD for products, including AI products. Enough to follow a design review, ask why this and not that, and spot the trade-off being made.

## Topics

One file per topic, added as I learn it. Files, not folders.

- HLD: client-server, services, monolith vs microservices
- HLD: caching, queues, and async work
- HLD: scaling and reliability
- LLD: components and interfaces
- LLD: data models
- LLD: state and flows
- Designing an AI system end to end
- Trade-offs and how to question a design

## Format

- **Baseline** → what I could do or explain before
- **What changed** → what I studied or tried
- **Evidence of progress** → a design I can now justify, including what I rejected and why
