# The Report

The layer that sits on top of the other four pillars. Raw logs mean nothing until they're turned into a decision.

- Monthly Report *(mandatory)* - one file per month, every month, even if a pillar had zero activity. A blank month is logged, not skipped.
- Weekly Report *(when possible)* - a shorter checkpoint every Sunday, to catch drift before a month has passed.


Structure: `2026/monthly/` and `2026/weekly/`, created as entries are earned.
